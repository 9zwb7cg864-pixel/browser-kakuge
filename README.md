# 大乱闘スマッシュストリート行動ファイト

オリジナルの2D対戦格闘ゲーム。PC（キーボード・ゲームパッド）とスマートフォン（タッチ）の両方で遊べます。
ブラウザで動き、インストールは不要です。

## 起動方法

- **公開ページ**：https://9zwb7cg864-pixel.github.io/dairantou-street-fight/ を開く（PC・スマホどちらも可）
- **手元で動かす**：`game/` フォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開く
  （`index.html` を直接ダブルクリックすると、ブラウザの制限で素材を読み込めません）
- テスト用URL：`?autostart&level=HARD`（すぐCPU戦）、`?autostart&training`（トレーニング）、`&fps`（FPS表示）

## 操作方法

| 操作 | 1P キーボード | 2P キーボード | ゲームパッド |
|---|---|---|---|
| 移動 | W A S D | 矢印キー | 十字キー / 左スティック |
| 弱P 中P 強P | U I O | テンキー 4 5 6 | X Y RB |
| 弱K 中K 強K | J K L | テンキー 1 2 3 | A B RT |
| ラッシュ | H（技のキャンセルは →→ でも） | テンキー 0（同） | LB / LT（同） |
| ポーズ | Enter / Esc | テンキーEnter | START |

- キー割り当てはタイトルの「操作設定」で変更できます（ブラウザに保存）。
- 左右同時押しはニュートラル、上下同時押しは上として扱います（レバーレスコントローラー対応）。
- ガードは後ろ入れ（しゃがみガードは後ろ下）。下段はしゃがみ、ジャンプ攻撃は立ちでガード。
- 投げ：弱P+弱K。つかまれた直後に弱P+弱Kで投げ抜け。後ろを入れながら投げると後ろ投げ。
- ダッシュ：前（後ろ）を2回すばやく。
- F2：当たり判定の表示 / F3：FPS表示
- **トレーニングの位置リセット**（スト6のトレーニングモードと同じ考え方）：キーボードR（またはBackspace）、パッドのBACKボタン。押したときの方向で場所が変わる。
  - リセットだけ：画面中央 ／ →：相手が右の画面端 ／ ←：自分が左の画面端を背負う ／ ↘：自分が右の画面端を背負う ／ ↙：相手が左の画面端
  - スマホはポーズメニューから選べる。リセットすると体力・ゲージも戻る。コンボが終わるとラッシュゲージも満タンに戻る。
- **スマホ**：左に方向パッド、右に6つの攻撃ボタン＋RUSH＋投げ、下中央にポーズ。縦持ち・横持ちどちらでも配置が変わります。

## コンボの仕組み（ストVIの組み方に準拠）

| 記号 | 意味 | 例 |
|---|---|---|
| ＞ | キャンセル：決まった通常技の動作を必殺技・超必殺・ラッシュで中断 | しゃがみ中K ＞ 虚環弾 |
| ， | 目押し：硬直が解けてから押す。有利フレームが次の技の発生より大きければつながる | 中P（＋7） ， しゃがみ中P（発生6） |
| ～ | ターゲットコンボ：キャラ固有の決まった連係 | 中P～強P |

- 必殺技キャンセルできる通常技：弱攻撃全般、中P・しゃがみ中P・しゃがみ中K、強P、しゃがみ強P。立ち強K・しゃがみ強K（足払い）は不可。1Pの立ち中K、2Pの立ち弱K・立ち中Kも不可。
- 連打キャンセルは弱攻撃同士だけ（例：しゃがみ弱K ＞ しゃがみ弱P ＞ 弱P）。
- カウンター（相手の技の出始めに当てる）：威力1.2倍・有利＋2F。
- パニッシュカウンター（相手の技の戻りに当てる）：威力1.2倍・有利＋4F（強攻撃は＋6F）。
- ラッシュから出した技は、ラッシュの勢いを残して滑りながら出て、戻りが5F短く、有利＋4F（スト6と同じく、ラッシュから出したその技にだけ付く）。ラッシュ強K ， 強P がつながる。ラッシュから出した通常技は、浮いた相手にも1回だけ当たる。
- **空中追撃の決まり（スト6の追撃カウント方式）**：浮かせた技がカウントを決め、追撃する技は「カウントがいくつまでなら当たるか」を持つ。当てるとカウントが増える。同じ技の2発目以降はいつでも当たる。
  - 旋風脚・パニッシュカウンター強K：カウント1で浮かせる → 昇穿（2まで）・空旋脚（2まで）・超必殺で追撃できる。通常技は当たらない。
  - 虚掌破：カウント0で浮かせる → しゃがみ強Pなどの通常技でも追撃できる。
  - 昇穿・超必殺が当たったら、そのあとは追撃できない（永久コンボ防止）。
- **昇竜コマンドの決まり（スト6と同じ）**：「前」→「下」→「前」がこの順に入れば出る。最初の前は→↘↗、下は↓↙↘、最後の前は→↘（↗は不可）。
  - 出る入れ方：→↓↘ →↓→ →↘→（→押しっぱなしで↓をはじいて戻す） →↙→ ↘↓↘ ↘↓→ ↘↙↘ ↗↓↘ ↗↘→ ↗↙→
  - ↓をはじいた瞬間にPを押す（→↘＋P）と出ない。↓を離して→に戻ってから押す。
  - 前に歩きながら↓↘→＋Pを入れると昇竜になる（スト6と同じ）。波動拳を撃つときは前を離して一呼吸おく。
  - ジャンプの踏み切り中は必殺技を出せる（↗から始める入れ方のため）。
- **昇竜SAの入れ方（スト6と同じ）**：必殺技を出してもレバー入力の記録は消えないので、昇竜の入力の後ろ半分を超必殺の入力に使い回せる（複合入力）。
  - 623＋強P → 236236＋K ／ 6236＋強P → 236＋K ／ 623＋強P → 36236＋K ／ 323＋強P → 6236＋K（レバーレス）
  - 超必殺の簡易コマンド：236236 は 23626・26236 でも出る（214214 は 21424・24214）
- **ラッシュキャンセルは1コンボに2回まで**（スト6と同じ）：1回にゲージ3本を使い、ゲージは6本なので2回まで。ラッシュの出始めに押した攻撃ボタンは、攻撃を出せるようになるまで覚えておく。
- 必殺技の先行入力：硬直が解ける5F前までに入れた必殺技は、動けるようになった瞬間に出る。
- 攻撃判定は手足の付け根まであり、密着・しゃがみ・画面端・重なった状態でも空振りしない。
- 飛び道具は撃った後しばらく超必殺でキャンセルできる。
- 発生（押したフレームを1F目とする）：1P 弱P4／中P6／強P9／しゃがみ中P6、2P 弱P6／しゃがみ弱P5／中P9／強P14。
- コンボ表（技表から↑↓で切替）の全コンボは `node tests/combos.js` で、人が押せるタイミングでつながることを確認済み。

## 独自のゲージシステム

| | ラッシュゲージ（6本） | 必殺ゲージ（3本） |
|---|---|---|
| 使い道 | その場ラッシュ（1本）／通常技からラッシュキャンセル（3本） | EX必殺技（0.5本）／超必殺（1本・2本） |
| 溜まり方 | 自然回復（前進中は速い）。使用後1.5秒は回復停止 | 攻撃を当てる・ガードさせる・食らう |
| 表示 | 体力バーの下 | 画面下（スマホでは上段） |

- 昇竜コマンド（→↓↘）は簡易入力 ↘↓↘ ・ ↓↘→↘ ・ →押しっぱなしで↓をはじく（→↘ / →↘→）でも出る。入力の最後が ↓↘→ のときは飛び道具を優先。
- →→でラッシュが出るのは、技をキャンセルするとき（キャンセルできる技が当たった・ガードされたとき）だけ。何もしていないときの→→は普通のダッシュ。その場でラッシュするときはRUSHボタン。
- ラッシュ中に攻撃ボタンでその技に派生。最初の1発はヒット・ガード時に＋4フレーム有利。
- 永久コンボ防止：ラッシュキャンセルはゲージの量で1コンボ2回まで、ラッシュキャンセル後はダメージ補正が追加、
  弱攻撃の連打キャンセルは3回まで、空中の拾い直しは回数制限あり、ヒット数に応じたコンボ補正。
- パリィ、ドライブパリィ、ドライブインパクト、アーマー付き反撃は入れていません。

## 対戦ルール

99秒・3ラウンド制・2ラウンド先取。タイムアップは体力の割合で判定、同時KOは両者にラウンド。
ラウンド開始演出・KO演出・勝利演出・再戦・キャラ選択に戻る、があります。CPUの強さは EASY / NORMAL / HARD / EXPERT。

## キャラの絵とモーション

- 絵は棒人間（Stick Fight風）。丸い端の太い線をつなげて描くので、関節で線が途切れない。1Pはシアン＋マフラー、2Pはマゼンタ＋ツノと2本のボロ布。
- 1フレーム＝全身を描いた1枚の画像。パーツを動かす方式や骨格アニメーションはゲーム内で使っていない（Pythonでポーズから毎フレーム描き直す）。
- モーションは現代格闘ゲーム（SF6など）の作り方を参考にした原則で作っている：
  - 溜めは小さく逆方向へ → 打ち出しは2〜3Fで一気に → 当たりの瞬間に止め → 戻りはゆっくり
  - 腰と足が先に動き、拳は遅れて届く（鞭のような動き）／踏み込み・かかとの浮き・体重移動
  - 速い攻撃には残像、マフラー・布は物理計算で揺れる
  - 歩きは接地中の足が体の速度で後ろへ動き、地面を滑らない
  - 前後ジャンプは宙返り、やられは頭と胴が大きくのけぞる
- 総フレーム数：1P 1081枚・2P 1200枚（計2281枚）。
- 生成：`python3 tools/build_chars2.py`（モーション定義は `tools/moves2.py`）。旧版の衣装付きの絵は `build_chars.py` / `moves.py` に残してある。
